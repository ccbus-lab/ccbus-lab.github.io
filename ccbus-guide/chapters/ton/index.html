Tonkeeper钱包安装教程

Tonkeeper是TON生态最流行的钱包应用。

安装方式

移动端

  1. 在App Store或Google Play搜索"Tonkeeper"
  2. 下载安装
  3. 创建或导入钱包

浏览器插件

  1. 访问Chrome网上应用店
  2. 搜索"Tonkeeper"
  3. 安装插件

安全提示

  • 妥善保管助记词
  • 不要泄露私钥
  • 注意钓鱼网站

TON链一键发币教程

在TON链上创建Jetton代币。

Jetton介绍

Jetton是TON链的代币标准，类似于ERC20。

创建参数

  • 代币名称
  • 代币符号
  • 精度（通常为9）
  • 发行总量
  • 图标URL
  • 描述

创建步骤

  1. 连接Tonkeeper钱包
  2. 填写代币参数
  3. 支付创建费用
  4. 等待链上确认

DeDust加池子(创建流动性)教程

DeDust是TON链上的主要DEX之一。

创建流动性池

  1. 访问 https://dedust.io/
  2. 连接钱包
  3. 选择"Pools" -> "Create"
  4. 选择代币对
  5. 设置初始流动性
  6. 确认创建

费率设置

DeDust支持不同的费率等级，根据代币类型选择合适的费率。

Ston.fi加池子(创建流动性)教程

Ston.fi是TON链上另一个主要DEX。

创建流动性池

  1. 访问 https://ston.fi/
  2. 连接钱包
  3. 进入流动性页面
  4. 选择代币对
  5. 添加流动性

优势特点

  • 低滑点
  • 多种池类型
  • 良好的用户体验

锁池平台TonRaffles使用教程

TonRaffles提供LP锁定服务，增加项目可信度。

锁池步骤

  1. 访问TonRaffles平台
  2. 连接钱包
  3. 选择要锁定的LP
  4. 设置锁定时间
  5. 确认锁定

锁池好处

  • 增加投资者信心
  • 防止Rug Pull
  • 提升项目信誉
