Simple Mint Tutorial

发表于 2026-01-21

CCBUS标准代币Mint预售创建教程

本教程将引导您通过CCBUS平台，完成一次100%去中心化的标准Mint预售创建。

一、什么是标准Mint预售？

标准Mint预售是指项目方将固定数量的代币存入一个智能合约。开启预售后，用户向该合约地址转入BNB（或其他链原生代币），合约将自动按照预设的兑换比例，将代币发送到用户地址。

核心前提：您必须已经在CCBUS上成功创建了自己的代币，才能为其创建预售。

二、预售核心特点与注意事项

核心特点

  • 100%去中心化：无需前端网页，完全由智能合约执行。
  • 转账即参与：用户只需向预售合约地址转账，即可自动获得代币，无需手动领取。
  • 灵活调整：项目方可在预售开始后，通过控制台修改“预售价格”和“每份数量”。
  • 无软硬顶：预售总供应量 = 预售总份数 × 每份代币数量。

⚠️ 重要注意事项

  1. 防范提前加池：在预售期间，可能有用户购买代币后立即创建交易对。强烈建议您使用“手动开启交易”功能，以防预售期间代币被加池交易。
  2. 勿将预售地址加入黑名单：请确保您的代币合约未将本次的预售合约地址设为黑名单，否则用户将无法收到代币。
  3. 准备充足资金：创建合约及开启预售均需支付链上Gas费，请确保钱包有足够的主网币（如BNB、ETH）。

三、创建标准Mint预售（分步指南）

第1步：连接钱包并选择网络

  1. 访问CCBUS预售创建页面：https://www.ccbus.org/#/presale/simpleMint（此处为演示链接，请以官网为准）。
  2. 点击页面右上角的“连接钱包”按钮。
  3. 在弹出的钱包（如MetaMask）界面中，确认连接的钱包地址。
  4. 在页面顶部选择您要创建预售的区块链网络（例如，在BSC链创建请选择“BSC”）。

第2步：填写预售参数并创建合约

成功连接钱包后，在同一个页面填写预售参数。

[此处为预售参数填写表单的示意图]

以下是一个参数填写示例：

  • 预售代币地址：粘贴您已创建好的代币合约地址。
  • 预售价格：0.1（表示1 BNB可购买0.1份预售额度）。
  • 每份数量：1000（表示每份额度包含1000个您的代币）。
  • 预售总份数：1000（本次预售总共出售1000份）。
  • 预售收款地址：预售结束后，所募集的BNB将自动转入此地址。

参数计算示例：按以上参数，若用户支付1 BNB，可获得 1 / 0.1 * 1000 = 10，000 个代币。本次预售总募集量为 1000 / 0.1 = 10，000 BNB。

填写完毕后，点击“创建合约”。系统会弹出确认框，请仔细核对信息，然后在钱包中确认交易并支付Gas费。

第3步：通过控制台管理预售

创建成功后，进入预售控制台页面（例如：https://www.ccbus.org/#/presale/console），找到您刚创建的预售项目。

[此处为预售控制台界面示意图]

如何开启预售？

  1. 在控制台找到您的预售项目，点击“开启预售”。
  2. 第一次确认（授权）：钱包弹出，授权合约使用您的代币。
  3. 第二次确认（转账）：授权后，钱包会立即弹出第二笔交易，将您设定的预售代币总量转入预售合约中。
  4. 两笔交易都成功后，预售即正式开启。用户现在可以向预售合约地址转账BNB来参与了。

如何结束预售？

您可以在控制台使用 “提取合约内代币” 功能，将合约中剩余的代币全部提出。一旦代币被提出，预售将自动停止，用户无法再购买。

[此处为结束预售功能按钮示意图]

四、常见问题

问：为什么我点击“创建合约”没有反应？
答：请按顺序检查：① 钱包是否已成功连接并解锁；② 是否选择了正确的区块链网络；③ 钱包内是否有足够的Gas费；④ 所有参数是否已填写正确。

问：预售开始后，价格或每份数量可以改吗？
答：可以。项目方可以在控制台随时修改“预售价格”和“每份数量”，调整将立即生效。

问：用户参与后，代币去哪里了？
答：用户转账后，代币会自动发送到用户购买时使用的钱包地址，用户无需任何额外操作。

问：预售募集的资金如何取出？
答：预售募集的BNB/ETH等主网币会实时、自动转入您在创建时填写的“预售收款地址”，无需手动操作。

如果您在操作过程中遇到任何问题，欢迎加入CCBUS官方社群获取帮助。

Price Curve Slippage Point and Constant Product (k) Line

发表于 2025-10-27 更新于 2025-11-04 分类于 Uniswap

基于下面的例子, 我们会画一个完整的「Uniswap V2 交易曲线」示意图:

初始池：1000 A + 2000 B
用户：用 100 A 兑换 B
手续费：0.3%
实际输出：≈ 181.64 B
恒定积 ( k = 2{,}000{,}000 )

🧮 一、恒定积模型原理

Uniswap V2 的价格机制遵循：

[
x \times y = k
]

在坐标平面上：

  • x 轴 = Token A 储备
  • y 轴 = Token B 储备
  • 曲线 ( y = \frac{k}{x} ) 是一条双曲线（即恒定积曲线）

📈 二、交易前后的储备与价格变化示意图

🟢 点 P₀：初始状态

  • ( reserveA = 1000 )
  • ( reserveB = 2000 )
  • ( P_A = reserveB / reserveA = 2.0 )

🔵 点 P₁：交易后状态

  • ( reserveA’ = 1099.7 )
  • ( reserveB’ = 1818.36 )
  • ( P_A’ = 1818.36 / 1099.7 = 1.653 )
  • 实际成交均价约 1.8164（中间价格）

📉 三、滑点（Slippage）展示

项目 含义 数值
初始价格 ( 1A = 2B ) 2.000
交易后瞬时价格 ( 1A = 1.653B ) 1.653
实际成交均价 平均约 1.816B 1.816
滑点比例 ( (2 - 1.816) / 2 ) 9.2%

🧠 解释：
用户预期 1A=2B，但由于交易影响价格曲线，使池内的 A 增多、B 减少，价格被推低，
因此最终实际获得的平均兑换比例变差。

🔄 四、k 恒定线变化对比

状态 reserveA reserveB A×B = k 备注
交易前 1000 2000 2,000,000 初始状态
交易后（理论恒定） 1099.7 1818.36 ≈2,000,000 恒定积保持
实际变化（含手续费） 部分 k 增加 → 手续费流入池中，k 略增大

手续费 0.3% 进入池子，使得流动性提供者 (LP) 的 k 略上升，
相当于 LP 赚取了一点手续费收入。

🪙 五、交易动态路径说明

在曲线上移动的轨迹表示价格逐渐变化的路径，
价格不是跳变，而是沿曲线连续变化的。

🧩 七、关键理解总结

概念 解释
k 恒定曲线 确保交易自动计算价格，不需要订单簿
滑点 交易越大，占池子越多，价格偏离越明显
手续费 每笔 0.3% 计入流动性池，增强 LP 收益
价格动态性 交易沿曲线移动，而非线性固定价格
k 的微增 因手续费注入，流动性略微提升

Uniswap V2 - How to do the math

发表于 2025-10-26 分类于 Uniswap V2

问题: 如果 reserveA = 1000, reserveB = 2000 所以初始价格 P_A = reseverB / reserveA = 2000/1000 = 2, 即 1A = 2B， 因此如果用户想用 100A 换取 B， 是否应该能换 200B ？ 再扣去手续费0.3% 相当于 200 * 99.7%？

回答: “用 100A 换 200B（再扣手续费）”这个计算是线性思维（即假设价格不变），而在 AMM（自动做市商）中，价格会随着交易发生而动态变化，这就是所谓的 滑点（slippage）。

详细推导如下👇：

🔹前提条件

池中初始储备：

  • reserveA = 1000
  • reserveB = 2000
  • 因此初始价格：
    $P_A = \frac{reserveB}{reserveA} = \frac{2000}{1000} = 2$，
    即 1 A = 2 B

手续费 = 0.3%
手续费后有效输入比例 = 0.997

🔹Uniswap V2 的核心恒等式：

$$
x \times y = k
$$

其中：

  • $x$ 是 token A 的储备量
  • $y$ 是 token B 的储备量
  • $k$ 是常数（交易前后必须保持不变）

🔹用户用 100 A 换 B 的详细过程

1️⃣ 用户输入的 A：

$$
\text{amountIn} = 100
$$

2️⃣ 扣除手续费：

$$
\text{amountInWithFee} = 100 \times 0.997 = 99.7
$$

3️⃣ 新的 A 储备：

$$
x’ = reserveA + amountInWithFee = 1000 + 99.7 = 1099.7
$$

4️⃣ 根据恒定积公式 $x \times y = k$，
交易前 $k = 1000 \times 2000 = 2,000,000$

所以：

$$
y’ = \frac{k}{x’} = \frac{2,000,000}{1099.7} \approx 1818.36
$$

5️⃣ 用户能拿到的 B 数量：

$$
\text{amountOut} = reserveB - y’ = 2000 - 1818.36 = 181.64
$$

✅ 结论

  • 用户输入：100 A
  • 实际获得：≈ 181.64 B
  • 实际价格：$\frac{181.64}{100} = 1.8164$
    （低于初始价格 2，原因是滑点）

🔹对比问题中的计算

问题中线性比例算得是：

$$
100A \times 2 = 200B
$$

再扣 0.3% 得 $200 \times 0.997 = 199.4B$。

➡️ 这是静态价格假设下的计算，但 AMM 实际上价格随交易动态变化。
由于用户一次性投入 100 A（池子总量的 10%），对价格影响很大，
所以用户只能拿到 181.64 B，而不是 199.4 B。

🔹总结
