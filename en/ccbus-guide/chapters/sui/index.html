Suiet is a popular browser wallet in the Sui ecosystem.

Installation Steps

  1. Visit Chrome Web Store
  2. Search "Suiet"
  3. Click install
  4. Create or import wallet

Create tokens on Sui chain.

Creation Parameters

  • Token symbol
  • Decimals
  • Total supply
  • Icon

Fee Description

Creating tokens requires small amount of SUI for Gas fees

Manage various permissions for Sui tokens.

Permission Types

  • Mint permission
  • Freeze permission
  • Admin permission

  • Transfer permission
  • Revoke permission

Create AMM Liquidity Pool Tutorial

Create AMM liquidity pools on BlueMove.

Preparation

  1. Prepare tokens and SUI
  2. Determine initial price

  2. Select token pair
  3. Set liquidity amount
  4. Confirm creation

Create Concentrated Liquidity Pool Tutorial

Create concentrated liquidity pools (CLMM) on Cetus.

CLMM Features

  • Concentrated liquidity
  • Custom price range
  • Higher capital efficiency

Creation Steps

  1. Select token pair
  2. Select fee tier
  3. Set price range
  4. Add liquidity

Create CLMM Liquidity Pool Tutorial

Create CLMM pools on Turbos.

Feature Description
